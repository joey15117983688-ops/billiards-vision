# 台球视觉识别与训练辅助系统

基于 Python 3.10、PyQt5、YOLO 与 OpenCV，面向台球比赛录像分析和训练辅助。当前支持本地视频与样本图片，覆盖球桌校准、袋口定位、台球跟踪、进球事件观察和考题标注。

## 当前功能

- **本地视频与图片识别**：支持单球、多球点选和全部识别；视频打开后默认暂停，播放/暂停使用同一按钮。
- **球房与球桌配置**：自动或手动校准台面、内库和六袋口，保存独立配置并设置启动默认值；校准有保存时间和上一版备份。
- **画面对齐**：以保存的校准为基准，标注随镜头平移、缩放和小角度旋转同步变化；人体局部遮挡不直接修改校准基准。
- **运动轨迹**：提供全部运动球、白球、其他球和所选球等显示范围，结合局部像素观察与有界帧历史处理快速运动。
- **进球事件计数**：结合入袋方向、入口交点、消失时间和袋口复核确认，支持候选、无法确认及判定修订；计数不是完整的斯诺克计分/裁判系统。
- **考题画圈**：在球桌截图中画圆、拖动位置、拖动边缘或输入直径调整大小；视频同步显示圆圈和序号，隐藏坐标文字，随球桌配置保存。
- **视频区域旋转**：横竖切换在当前视频区域内完成，保留其他操作控件。
- **实时视频前期模块**：独立拉流、有界最新帧缓存、超时重连和质量/连续性诊断。主界面尚未接入真实赛场视频流，详见[实时视频前期方案](docs/live_video_preparation.md)。

最新回归验证：原有 249 项与新增光照测试 22 项分别运行通过。已建立 35 个连续光照测试片段的生成与诊断流程，详见 [光照测试说明](docs/LIGHTING_CASES.md) 和 [A 阶段报告](docs/LIGHTING_ROBUSTNESS_REPORT.md)。实际新球房、摄像机和实时比赛的识别效果仍需实地验证，测试数量不代表识别准确率。

以下包含启动说明、环境资料和各阶段实现记录；当前交互以本节及文末最新说明为准。

```bash
cd billiards-vision
./scripts/start_dev.sh
```

也可以将 `PROJECT_ROOT` 设置为实际仓库目录，然后从任意目录执行：

视频按比例缩放，关闭窗口即可退出。目前为无声视频播放；真实摄像头尚未接入；台球桌与球采用专用模型进行点选识别。

素材说明见 `DEMO_ASSETS.md`，SDK 官方来源及平台限制见 `HIKVISION_SDK.md`。
视频已保存在 `data/snooker_match.mp4`，约 36 分 35 秒，854 × 480，约 25 FPS。本机启动无需联网。画面比分栏为潘晓婷／奥沙利文，包含连续击球、换局和转播镜头切换。
新机器拉取代码后，先运行 `.venv/bin/python scripts/download_demo_assets.py` 下载视频。

播放其他本地视频：

```bash
./scripts/start_dev.sh --video /absolute/path/to/video.mp4
```

## 样本图片与倾斜球桌框

```bash
# 默认样本图片
./scripts/start_dev.sh
# 直接播放原斯诺克录像
./scripts/start_dev.sh --source video
# 使用另一个图片目录
./scripts/start_dev.sh --images-dir /absolute/path/to/images
```

切换图片／来源会清空旧框并忽略此前尚未返回的识别结果；视频与图片共享同一个模型进程。图片读取失败时仍能切换下一张。

球桌框会在 YOLO 检测区域内提取绿色桌布的可见四角，用四边形绘制倾斜与透视桌面；球仍使用矩形框。球桌点选按四边形范围命中，视频缩放时四角按相同比例映射。对高度重叠的局部球桌候选先合并，再提取桌面。密集目标的名称尽量错开，移远的名称用引线连接。

这是绿色桌布几何后处理，不是新训练的旋转框／分割模型；桌面颜色不同、严重遮挡或四角不可靠时保留普通检测矩形，不编造四角。四边形对应桌布表面，不包含外围桌腿。轮廓方法参考 [OpenCV 4.10 轮廓特征](https://docs.opencv.org/4.10.0/dd/d49/tutorial_py_contour_features.html)。

这里加载的是训练集，能用于直观调试，不作为新场景准确率或独立测试集验收。

## 点击物体调用 YOLO

1. 启动后，点击下方 `YOLO：关闭` 开关，将其切换为开启。
2. 等待底部状态栏提示 YOLO 已开启，模型已就绪。
3. 点击视频中的物体；程序对点击当时的画面进行一次推理，用亮黄色框及中文标签标出实际预测目标，状态栏显示置信度。球桌门槛为 0.60，台球／白球为 0.25。
4. 未检测到包含点击位置的目标框时显示“未识别”。播放中的视频会连续识别，点选不会暂停；图片或手动暂停的画面可做单帧点选。
5. 关闭开关后清除目标框，不再提交点击识别。

使用本地 `models/billiards_v1.pt` 和 CPU，无需联网。该权重由 `yolov8n.pt` 微调得到，包含 `billiards_table`、`billiard_ball`、`white_ball` 三类，不回退到通用模型。
选择坐标按视频实际缩放比例映射，黑边不参与点选，视频区域均可点击。
YOLO 在独立后台进程中运行，避免本机 PyTorch 在 Qt 工作线程中推理时崩溃，也避免阻塞播放；关闭窗口会释放模型进程及临时文件。

此前红黄球测试录像的 6 个抽样画面各检出 1 张球桌和 12 个红黄球；该结果不代表新斯诺克录像的识别准确率。验证集规模有限，同一录像后段仍与训练画面相似，不能代表新球桌或新摄像头的准确率；白球已单列为“白球”类别，17 个验证白球全部正确检出，未额外误检；这仅代表本次验证集。训练与验证详情见 `TRAINING_REPORT.md`。低内存训练、白球分类及续训说明见 `LOW_MEMORY_TRAINING.md`。

## 识别当前画面的全部目标

播放中点击底部“识别全部”会后台持续识别所有目标，视频不暂停；仅开启 YOLO 不会自动识别全部；图片或手动暂停的视频执行一次识别。台球桌、台球、黑球、白球显示中文名称，播放时识别框持续更新。加载与推理期间禁止重复提交，底部显示实际推理更新频率。

点击“播放”会清除框并继续视频；关闭 YOLO 也会清除框。播放恢复或开关改变后，旧请求的结果不会重新覆盖当前画面。原有单目标点选仍可使用。

当前展示模型的实际预测，使用同一置信度门槛。新斯诺克转播录像中的比分数字和广告仍可能被误检为台球；“全部”指当前模型检出的全部目标，并不保证找到画面里的每一个真实物体，也没有独立红球／蓝球等颜色分类。

## 袋口自动检测

底部“自动检测袋口”按钮会暂停当前视频，独立检测球桌内库与袋口，按透视方向绘制入口区域。绿色表示局部图像验证通过，黄色表示几何估算，红色表示未定位。只有六袋全部验证通过才标记完整；切图或继续播放会清除旧结果，再次点击可重新检测。无需开启 YOLO。

```bash
.venv/bin/python scripts/test_pocket_detector.py --video data/billiards_table.mp4 --at 5
.venv/bin/python scripts/test_pocket_detector.py --image data/dataset/images/train/demo_00.jpg
```

JSON、原图、台面 mask、袋口 mask、透视展开图及标注图自动保存到 `data/debug/pocket_detection/`。支持贴边袋腔与袋网特征：`demo_15.jpg` 可确认六袋；`000001.jpg` 可确认五袋，被球员遮挡的右下袋显示估算。实现、测试结果及限制见 [POCKET_DETECTION_REPORT.md](POCKET_DETECTION_REPORT.md)。

## 台球桌、球体与台外过滤

“识别全部”和点选识别保留台球桌和台面内所有球：黑球标“黑球”、白球标“白球”，其他颜色统一标“台球”。台球桌优先使用可靠台面四边形显示倾斜轮廓，即使 YOLO 漏掉整桌框也可由台呢几何补充。球体沿用 YOLO 候选，黑白球通过颜色、轮廓和位置验证补充并去重；没有重新训练或改动权重。

图片和视频完整显示原始画面，桌外内容不隐藏；仅过滤桌外识别结果，不给桌外目标加框。未可靠定位台面时仍显示原图，但不输出球目标。当前台面定位针对绿色台呢，强反光、严重遮挡和极暗画面仍可能漏检，黑白球规则分数为质量评分。

验证：49 项自动测试通过。实际界面中 `000001.jpg` 检出 1 张台球桌、19 个台球、1 个黑球、1 个白球；`demo_15.jpg` 检出台球桌和 12 个台球。已验证台球桌与黑白球点选、桌外点击过滤、桌外结果过滤及六袋口功能。

袋口与边界支持局部亮度归一化：`1770626791.jpg` 的右侧内库与两个角袋已修正，0.55～1.5 倍数字亮度测试均定位六袋。识别结果过滤与袋口使用一致的台面几何。详见袋口检测报告。

## 球桌物理坐标（mm）

点击“坐标模式”保持视频当前播放／暂停状态，自动使用四条可靠内库边界建立图像到毫米平面的 Homography，并开启点选识别。屏幕左上内库交点为 O(0,0)，沿上边向右为 +X，沿左边向下为 +Y。鼠标移动时底部显示 X/Y 毫米坐标；台面外、画面外及边界不可靠时不返回坐标。

当前采用用户确认的 **3569 × 1778 mm 参考尺寸**。点击尺寸按钮可修改内库之间的 X/Y 比赛区域尺寸并保存到 `config/table_dimensions.json`，重启后生效。竖向或旋转机位应按界面 X/Y 对应边填写实际尺寸。当前左上角排序依屏幕方位，不跨摄像头跟踪同一个物理角。

点选黑球、白球或其他台球时，底部列出其检测框中心换算的 X/Y（不以点击位置换算球心）；坐标模式下绘制球心及到两轴的虚线。点选台球桌不报告球心，换图或播放清除旧球心。关闭坐标模式后仍可点选球查看球心读数，悬停读数与坐标辅助线关闭。完整原图和桌外识别结果过滤保持不变。

坐标精度取决于尺寸与内库定位；当前是检测框中心在台面上的透视投影，未校正镜头畸变和球心高度视差，小数位不代表实测精度。54 项自动测试通过，覆盖透视往返、四角毫米值、尺寸校验、球心计算、悬停映射与切图失效；真实 Qt 联调验证了实际 YOLO 球心、尺寸保存及坐标辅助线。

## 视频实时 YOLO

视频播放中，选球后播放会进行单球局部推理；显式点击“识别全部”后，后台子进程才进行全目标推理。播放器继续解码和显示。CPU 推理不强求每个视频帧都运行：同一时间最多一个请求，推理完成后取下一张最新帧，忙时跳过中间帧，不积压完整图片。

识别框在两次 YOLO 之间通过低分辨率稀疏光流跟随移动。最多保留 16 张最长边 640 的灰度历史帧（16:9 视频约 3.5 MiB），用于把延迟返回的框对齐到当前画面；超过历史窗口的结果丢弃。切换来源、开关 YOLO、视频结束归位时校验世代，防止旧结果串入新画面。

播放中点选当前框可持续显示该目标的球心坐标，坐标模式不再强制暂停。短时遮挡、快速运动可能丢失所选目标，需要重新点选；光流辅助用于帧间位置传播，身份关联与轨迹记录见下方最新说明。手动暂停／播放仍正常，静态图片继续单次识别。袋口按钮仍是对冻结帧独立验证和保存的操作。

60 项自动测试通过，包括光流位移、延迟框对齐、历史上限、单个在途请求、旧来源丢弃及不暂停的点选。真实 Qt 联调跨视频循环连续得到 62 次推理结果，验证开关、暂停／继续、坐标及切换图片；测试截图在 `logs/live_yolo_video_ui.png`。推理速度由本机 CPU 和图像大小决定，状态栏显示实测更新频率。

## 单球优先（当前播放规则）

开启 YOLO 只加载模型，不自动检测所有球。点选一个球后点击“播放”，只显示并跟踪该球；后台只对其当前位置附近的小区域运行 YOLO，不执行整桌全目标推理。播放中从全部结果点选球，也会转为单球模式。单球跟丢或视频结束归位时不自动回退到全部识别。

只有显式点击“识别全部”才显示台球桌及所有检出的球，该按钮可以从单球播放切回全部模式。切换来源或关闭 YOLO 回到等待选球状态。原坐标功能、桌外过滤、完整画面显示保留。

### 完整场景校准

点击“自动检测袋口”暂停播放并在后台重新读取当前帧，依次运行模型加载、台呢内库定位、六袋口检测验证、台面球体识别。按钮显示“校准中…”，状态栏显示当前阶段，完成后统一替换旧球桌、球体、袋口结果，并更新坐标平面。该操作只在点击后执行。

校准会将旧边界作为对照，生成并比较不同边界。失败会显示原因并恢复原结果；袋口分别标记已验证、估算、未定位，不将估算当作验证成功。校准后点击播放继续识别球体；固定镜头的台面与袋口区域保持使用，切换媒体后会恢复各自已保存的校准。当前流程针对软件已支持的本地视频和图片来源；不改变或重新训练模型权重。

自动校准现在会在完整球桌画面中寻找内库边界，不再只对贴住画面边缘的球桌执行向内修正。普通识别、点选球桌与校准结果使用完整的连续同色台面范围，包括同色库边；黑色和木质外框排除。毫米坐标与袋口几何仍使用独立的内库平面，不再用坐标内沿裁掉识别范围。

自动结果仍不合适时，点击“手动校准”，按提示点出台呢内沿左上、右上、右下、左下四角，再点六个不同袋口的中心（袋口顺序不限）。可撤销、重新点选、取消；点击“保存并重新识别”会按当前媒体来源保存归一化位置，更新球桌与袋口。手动袋口标记为“人工确认”，不是自动视觉验证；同一来源在打开、切换返回、重启软件或视频回到首帧时，会自动恢复人工台呢与袋口位置，直接点选或继续识别即可；再次点击“自动检测袋口”会将当前边界视为纠错反馈，比较其他方案；只有证据明显改善才应用自动修正，原始人工文件单独保留。更换镜头位置后请重新点选，或在手动校准窗口点击“恢复自动校准”。不同来源的配置分别保存在 config/calibration/。

手动校准窗口支持滚轮以鼠标位置为中心缩放、“放大 / 缩小”（最高为适应窗口比例的 12 倍）、拖动或“移动画面”模式、方向键移动，以及“适应窗口”和数字 0 恢复全图；还可最大化窗口。单击才添加标注，拖动不添加点。标注按原图归一化坐标保存，与窗口大小、缩放和拖动无关。

每次保存新的手动标注，会在后台将该帧原图、台面掩膜与六袋口中心标签积累到 data/calibration_samples/。每个样本包含 image.png、table_mask.png、annotation.json；相同帧、标签及来源不重复保存。标签明确区分已标注的台面 / 袋口和未标注的球体。样本保存在本地，尚未训练模型；已有手动校准立即用于当前来源的识别，样本积累用于后续台面分割 / 袋口关键点模型的训练与独立验证。现有球体检测模型不直接使用这套不含球体标签的样本，权重不会因保存标注自动改变。


### 有反馈的自动纠错

正常识别首次通过台呢、黑边与六袋口验证时，会固定并保存自动范围，切换 / 重启后检查当前画面证据再恢复。若已保存的自动修正与当前画面不符，不会退回该修正已经替代的旧人工范围；会提示重新识别或校准。

点击“自动检测袋口”表示当前结果仍需纠正。系统记录当前被否定的边界，比较不同曝光和分辨率下的定位，再分别尝试向内、向外、单边和双边修正。后续尝试逐步扩大范围并加入更细尺度，避免重新选回已否定的边界。比较依据为台呢覆盖率、边缘黑色占比、可见边线以及六袋口 / 两侧中袋证据；它们是规则评分，不是准确率概率。自动替换需要明确的证据改善，且不能减少已验证袋口和中袋数量。亮度等原因导致袋口无法验证时，会保留估算状态，不因台面调整而伪报袋口成功。

未找到更可靠的候选时明确显示“保留原边界”；达到最大搜索范围后提示手动校准，不声称每次重试都必然改进。异常时恢复校准前的识别和跟踪状态。不同来源的自动结果保存为 config/calibration/*.auto.json，纠错次数、被否定范围、画面摘要及前后指标保存为 *.feedback.json；人工原始标注保持独立。重新保存人工标注或恢复自动校准会清除该来源的自动修正及旧纠错历史。这是基于画面证据和反馈的有限搜索，不会训练或修改模型权重。


### 同色台面范围与坐标平面

识别范围从台呢主色与连通性确定，包含与台面同色、相连的绿色 / 蓝色边缘区域；对亮暗变化、球体和球杆造成的小范围缺口进行连接与四边拟合，并检查同色连通区域的覆盖率。不因内部边线更清晰或旧缓存更窄而裁去连续同色带。黑色 / 木质框、被框隔开的同色地面不纳入该范围。

显示和目标范围字段 polygon / scope_polygon 使用上述完整同色范围；playable_polygon、袋口透视几何保留内沿平面，显示毫米坐标与当前识别范围对齐。人工标注仍用于确定内沿和袋口。既有人工和自动配置读取时会重新恢复同色识别范围，无需重做标注；它们的原始内沿坐标不被覆盖。该区分应用于初次识别、点选持续识别、校准、袋口显示、切换和重启恢复。


### 识别操作

“自动检测袋口”合并原自动校准入口：重新读取当前画面，只更新球桌和六个袋口，不加载球体模型。手动校准继续保留。

“全部识别”点击后变为“取消识别”，推理期间也可取消；取消清除球体标记和轨迹，迟到的旧推理结果不再显示。球桌与袋口校准独立保留。

轨迹下拉框提供全部运动球、白球、其他球和当前所选球四种范围。切换只改变显示范围，不删除已记录的位置。坐标轴、鼠标坐标和球心坐标统一使用当前显示的球桌范围；毫米换算取决于已配置的球桌尺寸。

前三种轨迹模式独立启动整帧球体跟踪，播放时无需点选或开启“全部识别”，只画轨迹，不添加所选球框。只有“当前所选球运动轨迹”使用点选目标；“关闭轨迹”隐藏所有轨迹并停止独立轨迹推理（显式的全部识别或所选球识别继续保留）。默认关闭轨迹。

检测袋口后显示“隐藏袋口识别”，可切换为“显示袋口识别”；隐藏袋口辅助线、框和标签不删除检测结果、校准或坐标数据。再次自动检测会重新显示辅助标记。


### 实时进球检测

视频模式点击“进球检测”后，系统按当前播放帧观察所有可分离球体，无需点选或等待 YOLO；没有袋口结果时先自动定位。使用台呢颜色与球体形状观测，并在袋口附近短时验证实际像素模板，补充被袋口遮住的球体。真实进入可靠袋口、持续消失并完成袋口局部清晰复核后确认；不会要求其他球全部静止，单纯漏检仍不确认。观察时间与播放时间同步，暂停后不增加证据。

记录与关键帧保存在 `data/pocket_events/`。离线命令、合成视频回放和真实素材验证见 `POCKET_EVENT_REPORT.md`。现有短视频尚不能证明真实进袋准确率；人工校准只有中心而无入口形状时会要求复核。此版本不计分、不评级，也不训练模型。


画面右上角“旋转全屏”可放大观看：竖屏视频顺时针旋转 90 度后等比例全屏显示，横屏视频直接全屏；袋口、边界、轨迹、坐标与点选映射同步变换。再次点击“退出全屏”或按 Esc 恢复原窗口，不改变原视频与标定数据。

“进球检测”旁的括号显示当前视频已确认的所有球进袋总数（包括白球），疑似/未知不计数，修订撤销会回减。开关检测或重新校准不会清零；切换来源、重新播放视频时重新计数。


### 球房／球桌默认配置

自动校准或手动校准成功后自动保存完整结果（台面、识别范围、六袋口），后续打开直接恢复，不再根据开头画面重新拟合。暂时遮挡或黑帧不会触发重新定位；同宽高比的分辨率变化按比例恢复，宽高比改变则提示重新选择或校准。

同一球桌使用不同视频文件时，在校准后点击“另存为配置”，例如“某俱乐部 · 1号桌”。首次创建的配置自动成为默认，也可选择其他配置后点击“设为默认”；下次启动直接载入默认配置。每张新球桌或新机位首次校准一次，此后通过下拉框切换，球桌范围、袋口、尺寸分别保存，互不覆盖。重新自动或手动校准会更新当前选中配置。

“按视频／图片分别保存”保留按来源记忆的原有用法。配置保存在本机 config/venues/，原有来源校准保留在 config/calibration/。镜头或球桌实际位置改变时，重新校准并保存当前配置。

### 考题画圈

完成球桌校准后，点击“考题”打开当前球桌截图。截图按原画面比例显示；点击放置圆圈，按住拖动调整大小，也可输入“直径（台面短边 %）”。已有圆圈可按住圆内拖动位置、拖动圆边调整大小，也可选中后输入直径或删除；点击“画圆”继续放置。视频同步显示圆圈，中心使用小号清晰序号（1、2、3…），隐藏坐标数据和中心十字；横竖切换时位置和大小同步变换。

坐标沿用球桌坐标系（原始画面左上为原点、X 向右、Y 向下），单位 mm；默认尺寸为参考值，准确毫米值需要设置实际球桌尺寸。弹窗使用打开时的截图，视频可继续播放。圆圈自动保存在当前视频／图片或球房球桌配置内，重新打开自动恢复；相机位置变化需重新校准。

校准记录现在会显示保存时间，并在有实际变更时保留上一版 `.auto.previous.json`。自动纠错没有找到更可靠的替代结果时，蓝框、内库和袋口坐标整套保留；外侧蓝框需要有明确的台呢覆盖改善才替换。局部凸出、人体遮挡不再用极端轮廓点牵引整条边。固定配置不会在启动或播放时重新拟合；视频本身若有镜头移动、裁剪或缩放，同一固定校准无法同时匹配变化前后，应在目标镜头位置主动校准。

### 镜头移动／缩放时的标注对齐

保存的校准作为固定基准。播放时通过球桌边沿分散的特征点估计镜头平移、缩放和小角度旋转，将蓝框、六袋口、考题圆圈、球桌坐标及识别范围一起映射到当前画面。对齐使用固定参考画面，避免连续帧变换累计漂移；不会把播放中的变换写回校准文件。新的校准记录包含压缩参考画面，重启后也可对齐。旧记录首次打开时以可见台呢建立本次播放的参考，仍保留磁盘原值。

对齐在 720 像素缩略图上每四帧检查一次，固定保存一份参考，内存不随播放增长。需要来自至少三个区域、横纵跨度超过球桌一半的特征支持；人体局部遮挡不能决定整体位置。证据不足时保留最近可靠位置并显示提示。大幅换机位或不同球桌仍需选择相应配置或校准。

### 实时赛场视频前期准备

新增独立拉流基础模块、输入质量/连续性检查及诊断脚本，支持先用本地视频模拟实时输入。当前桌面入口仍保留本地文件播放，网络接入与比分保护规则尚未接入主界面；实地协议、延迟、画质和识别阈值将在接入赛场后验证。详见 [实时视频前期方案](docs/live_video_preparation.md)。

### 长视频中的袋口漏记修正

打开软件、载入或切换视频后只显示首帧，等待点击“播放”。播放与暂停共用同一个按钮：播放中显示“暂停”，暂停后显示“播放”，再次点击从当前位置继续。视频结束后停在首帧，不自动循环；图片模式及校准过程中禁用该按钮。
