## 2. 样本及可复现性

5 个原片时间段，**35 个连续片段 / 5,850 帧**；5 个原始照明对照，30 个合成光照变体。保持源分辨率与 FPS，使用 FFV1/AVI 无损编码。原片哈希与第一阶段一致；构建、评估均检查哈希，构建回读所有生成帧并确认与生成前像素 SHA256 一致。参数、种子、时间范围、源尺寸/FPS、校准引用及真值在 manifest 中完整记录。

早期绿色覆盖 normal、红/蓝/紫/青通道增益、局部色斑、慢变色、2 Hz 闪烁、局部裁切高光、阴影、亮度梯度、混合光、噪声；其它片段覆盖至少 normal、整体偏色、局部色斑、闪烁、过曝，蓝色还额外覆盖蓝/紫增益。每个扰动连续经过正常 → 渐变 → 受扰 → 恢复，没有只测孤立截图。

新增测试在同一环境独立构建两份受控小序列，对照 manifest、容器及解码像素哈希一致。本次本地生成文件约占 6.0 GiB，未覆盖原片。大样本全量逐帧生成/回读校验通过；跨库版本仅以解码像素哈希核验，不保证编码容器跨版本字节一致。真实视频取样窗口与全量参数见 `LIGHTING_CASES.md`。

真值边界：本轮只有 Codex 稀疏截图视觉审阅；模板可由维护者手工补充，**尚无人类逐帧真值**。`annotation_kind=manual_minimal_review` 表示手工维护的最小记录，不能当成人类完整标注。几何相对原帧不变来自纯光度构造；手臂/球杆“存在”来自抽查；黑白球逐帧可见性、实际入袋标签和目标袋口具体遮挡均保留 unknown。不把旧自动 fixture、既有回归期望或新模型结果当人工真值，不输出真实彩灯准确率。

## 3. 当前算法在不同光照下的输出

以下全部使用**未改动的生产算法**：逐帧像素观察＋固定参考几何适配器；相机对齐独立诊断，未接入保护许可；YOLO 未参与彩灯测量，也未模拟其结果。表中 B/W/C 为每帧黑/白/其它球**检测数量中位数**，不是召回率。

- fresh 缺表：每秒 0/.36 秒两个相位及最后帧的台面重新检测失败次数/快照数；不能解释为全部视频帧漏检率。
- 四角差：与同源、同时间 normal 快照配对的最大角点偏移，消除轮廓起始顺序差异；缺表帧不计偏移，须同时看缺表列。不是人工位置误差。
- 固定袋口最少 observed：所有快照中，沿用原片参考台面时被局部验证为 observed 的最少袋数；其余可能 estimated/missing，不能等同人工已验证袋数。
- clear% / 对齐 lost%：该输出在连续帧中所占比例，不是遮挡分类准确率或相机移动真值。
- POTTED：剪辑窗口中已输出并按 `(shot_id, ball)` 汇总的最终裁决数；不是 UI 全片总数、TP 或 FP。没有额外 EOF 补判，尚未输出的候选也不计入。其它状态在本地 JSON 中保留。

## 4. 已复现的问题与后续建议

1. **台面候选随颜色/亮度显著漂移。** 早期绿色的紫色增益最大四角差 323.5 px，闪烁最大 384.3 px（约源短边 1080 px 的 35.6%）；对应最差快照仍返回 `geometry_reliable=true`。红色和混光分别有 13/17 个台面快照未检测到；它们不计入偏移统计，所以不能只看可检测帧的最大偏移。这里测的是重新检测结果，**没有证明或造成保存校准被覆盖**。后续先做 B 的固定基准与许可，再按 C 改观测。
2. **黑白身份/数量对照不稳定。** 早期绿色 normal 的 B/W/C 中位数为 1/1/9；红、蓝、紫、青增益下白球均为 0；局部红斑黑球降至 0；阴影下黑球类别中位数变为 7、白球为 0。没有人工逐帧真值，不能把每个变化都算误分类，但已能复现颜色分类及局部主色依赖。B 先限制不可靠帧确认资格，C 再引入局部对照和 unknown 身份。
3. **固定台面并不能独自保证袋口观测可靠。** 早期绿色红/蓝/紫/青、慢变色、闪烁及混光均出现固定台面下 observed 袋数为 0 的快照；局部高光最少 4。说明只冻结四角不能替代局部袋口证据评估。后续需 B 的局部质量状态，再在 C 评估局部验证。
4. **scene_clear 不是画质可靠性信号。** 后期绿色闪烁 B/W/C 中位数全为 0，`scene_clear` 仍为真约 99.2%（精确值见表/JSON）；对齐在本轮所有案例中均未标 lost。不能据此认定这些帧能支持球体/入袋观察。早期绿色整体蓝/青增益 clear 比例反而高于 normal；不能将比例提高当遮挡识别改善。B 应显式评估几何/光照/局部袋口，而非复用单个遮挡布尔值。
5. **入袋输出对扰动敏感，但尚无新增误报结论。** 早期和后期绿色 normal 分别输出 1 个 POTTED；早期局部红斑/蓝增益/闪烁/混光等未输出 POTTED，后期红增益/闪烁未输出 POTTED。缺少独立真值及可见性标签时，0 既可能是观测不足后的合理保守，也可能漏掉应能观察的事件；不能直接记作 FN。未在本集证明新增进球误报，**也未证明坏帧保护安全**。B/D 仍需受控保护测试，不能提前宣布修复。
6. **正常素材原有问题单列。** 倾斜视角 normal 的像素观察检测数量中位数已为 0，fixed 袋口 observed 最少 4；后期绿色 normal 的 fixed 袋口验证也有 observed=0 快照，其参考为既有 300 秒 fixture。它们并非本轮彩灯引入，需先确认参考适配及人工入口/球体标注，不能只归因光照或把全局球数增加当进步。

本轮相机对齐最大输出位移约 1.8 px，远小于部分台面重新检测的数百像素漂移；这只是本集结果，不覆盖 B 将来的模拟对齐失效测试。单个扰动强度/固定种子、少数原片和稀疏几何快照不足以推断所有灯色、曝光或机位。

A 仅保存上述失败/待复核案例，没有调整任何阈值或生产判断。
